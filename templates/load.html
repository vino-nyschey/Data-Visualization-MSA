Multiple Sequence Alignment (MSA)

This web page serves as a tool for the visual exploration of Multiple Sequence Alignments (MSA) in the context of protein sequences. The underlying Python script is designed to parse sequence data, extract essential details, and compute coverage and consensus percentages for subsequent visualization.

Key Components

  • Amino acid coloring is customized based on alignment methods, including Clustal, Lesk, and Custom.
  • Function, that reads a JSON file containing pertinent information about protein sequences. Extracted details include organism, protein name, engineered status, sequence length, and the number of chains.
  • Another Function, that responsible for processing FASTA files containing protein sequences, this function extracts sequence IDs and their corresponding sequences, presenting the data as a list of tuples.
  • Third Function, operating on a list of sequences, this function calculates coverage percentages and consensus percentages for each position within the alignment.

Important Note: It is crucial to note that this tool is specifically tailored for visualizing pre-aligned MSA files in FASTA format.
