Protein Sequence Data Visualisation

By visualising the relationships between proteins, the analysis of these proteins is faster, more effective and enables researchers to communicate their findings. We visualised 89 proteins using a pre-provided FASTA-file containing the full sequences as well as the protein IDs. With help of ProteinDataBank (PDB), further information about the given sequences were extracted. This information is shown in the table below. For more details about each entry, refer to the 'Details' button. The rows in the table can be sorted according to each column name by clicking on this name. Additionally to this overview, further charts to visualise specific aspects of the proteins have been implemented (see Charts/Visualizations). A multiple sequence alignment of clusters of the proteins can also be found and used for analysis (see MSA).
