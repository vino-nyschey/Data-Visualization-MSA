Protein Data Visualization

By visualizing the relationship of proteins, the analysis of these proteins is faster and enables the researchers to communicate their findings. We visualized 89 proteins using a FASTA-file, which contained the sequence as well as the protein ID. With help of PDB, we extracted further information about the given sequences. This information are shown in the table below. It is possible to get more details about each entry (Details button). Furthermore, the rows can be sorted according to each column name by clicking on this name. Besides this overview, we implemented further charts to visualize specific aspects of the proteins (Charts/Visualizations). Moreover, we constructed a multiple sequence alignment of clusters of proteins (MSA).
